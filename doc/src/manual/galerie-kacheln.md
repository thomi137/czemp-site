# Galerie-Kacheln anpassen

Auf der Galerie-Seite siehst du grosse Bild-Kacheln, eine pro Kollektion. Beim Drüberfahren mit der Maus
erscheint ein Text-Overlay. So änderst du Bild oder Text:

**Schritt 1**
Gehe im Backend auf Seiten → Galerie → Bearbeiten.

**Schritt 2**
Klicke auf die Kachel, die du ändern möchtest. Rechts erscheinen die Einstellungen.

**Schritt 3**
Um den Overlay-Text zu ändern: Klicke direkt auf den Titel oder den Beschreibungstext in der Kachel und schreibe
deinen neuen Text.

**Schritt 4**
Um das Bild zu ändern: Klicke auf das Bild in der Kachel, dann auf das Foto-Symbol in der Toolbar und wähle ein
neues Bild.

**Schritt 5**
Um den Bildausschnitt (Fokuspunkt) anzupassen: Nutze den Regler im Einstellungspanel rechts.

**Schritt 6**
Klicke oben rechts auf «Aktualisieren».

> Die Kacheln auf der Galerie-Seite müssen manuell aktualisiert werden, wenn du eine neue Kollektion anlegst.

# Reihenfolge der Werke steuern

Innerhalb einer Kollektion kannst du die Reihenfolge der Werke selbst per Drag-and-Drop festlegen — diese
Reihenfolge gilt dann sowohl in der Verwaltung als auch auf der öffentlichen Kollektionsseite.

**Schritt 1**
Gehe zu Werke in der linken Navigation.

**Schritt 2**
Filtere die Liste oben auf die gewünschte Kollektion (z. B. «Kork»).

**Schritt 3**
Jede Zeile hat links ein kleines Griff-Symbol (sechs Punkte). Fasse eine Zeile an diesem Griff und ziehe sie an
die gewünschte Position.

**Schritt 4**
Lass die Zeile los — die neue Reihenfolge wird automatisch gespeichert, kein zusätzlicher Klick nötig.

> Das Griff-Symbol funktioniert nur, wenn die Liste auf eine bestimmte Kollektion gefiltert ist — bei «Alle»
> ist es absichtlich deaktiviert.

> Ein neu einer Kollektion zugewiesenes Werk erscheint automatisch am Ende der Liste, du musst nichts von Hand
> nachziehen.

# Kollektion anlegen

Kollektionen gruppieren deine Werke (z. B. «Kork», «Fussbilder»). Lege zuerst die Kollektion an, bevor du Werke
zuweist.

**Schritt 1**
Klicke im linken Menü auf Werke → Kollektionen.

**Schritt 2**
Gib unter «Name» den Namen der Kollektion ein.

**Schritt 3**
Lasse das Feld «Slug» leer — WordPress füllt es automatisch aus.

**Schritt 4**
Klicke auf «Neue Kollektion hinzufügen».

> Der Name der Kollektion erscheint automatisch als Seitentitel, wenn jemand die Kollektion aufruft.

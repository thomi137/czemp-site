# Neues Werk hinzufügen

So lädst du ein neues Gemälde oder Werk auf die Website.

**Schritt 1**
Melde dich im WordPress-Backend an: claudia-zemp.ch/wp-admin

**Schritt 2**
Klicke im linken Menü auf Werke → Neues Werk hinzufügen.

**Schritt 3**
Gib den Titel des Werks ein (z. B. «Ohne Titel» oder einen konkreten Namen).

**Schritt 4**
Schreibe einen kurzen Kurzbeschrieb im Feld «Auszug» (rechte Spalte). Dieser erscheint unter dem Vorschaubild.

**Schritt 5**
Klicke rechts auf «Beitragsbild festlegen» und lade dein Foto hoch (JPG oder PNG).

**Schritt 6**
Wähle rechts unter Kollektionen die passende Kollektion aus.

**Schritt 7**
Klicke oben rechts auf «Veröffentlichen». Das Werk erscheint sofort auf der Website.

> Das Bild wird automatisch auf die richtige Grösse zugeschnitten — lade ruhig das Original hoch.

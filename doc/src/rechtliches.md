# Rechtliches

Die Website verkauft Originalwerke, hatte aber weder ein Impressum noch eine Datenschutzerklärung — beides ist in
der Schweiz gesetzlich vorgeschrieben, auch für Privatpersonen ohne Firma. Beide Seiten wurden ergänzt und sind
über die Fusszeile von jeder Seite aus erreichbar.

Kurz zusammengefasst, was drinsteht: wer für die Inhalte verantwortlich ist, dass keine Cookies für
Besucher:innen gesetzt werden (keine Analyse- oder Tracking-Software im Einsatz), dass Schriftarten lokal von der
eigenen Website geladen werden (keine Datenübertragung an Google), und welche Rechte Besucher:innen bezüglich
ihrer Daten haben.

**Hinweis:** Dieser Text ist ein solider Standardentwurf für eine Privatperson in der Schweiz, aber keine
anwaltlich geprüfte Rechtsberatung.
